## Research and modeling priorities

| Evidence | Use in this project |
| --- | --- |
| **Historical precedent.** Davis, Perera and Swartz used hierarchical empirical Bayes for ball outcomes given batter, bowler and state. CAMP uses projected runs to compare performance in context. | Build the repair baseline with earlier-only role and opposition priors and a contextual reference outcome. Pool sparse contexts rather than treating every head-to-head record as a separate effect. [T20 simulator](https://www.sfu.ca/~tswartz/papers/t20sim.pdf) · [CAMP](https://arxiv.org/abs/2307.13700) |
| **Current cricket work.** A 2026 preprint values runs relative to context and centers the wicket effect on expected dismissal risk. A separate 2026 preprint demonstrates that a coherent Markov chase engine can still miscalibrate win probabilities. | Test state-dependent wicket values with support checks. Compare first-innings projected-score pressure and chase leverage separately. Require probability calibration and player-ranking value from any added simulator. [Runs Above Expected and Wicket Effect](https://arxiv.org/abs/2608.18020) · [Calibration and leverage preprint](https://arxiv.org/abs/2608.14696) |
| **Model choice now.** Quantile forecasts can be evaluated with pinball loss plus coverage. CatBoost supports direct quantile objectives. Distributional regression can model context-dependent location and spread. | Compare repaired B0 and pooled pressure effects with a **heavy-tailed, workload-aware forecast** and a **direct quantile tree model**. Start with the same features, match units and reference target. Compare calibration, paired loss and observed top-ten outcomes. [Quantile diagnostics](https://doi.org/10.1146/annurev-statistics-032921-020240) · [CatBoost regression objectives](https://catboost.ai/docs/en/concepts/loss-functions-regression) · [Distributional regression](https://cran.rstudio.com/web/packages/brms/vignettes/brms_distreg.html) |
| **Follow-on experiments.** NGBoost estimates a predictive distribution. Adaptive conformal research addresses changing coverage in online forecasts. TabPFN has shown strong results on small tabular benchmarks. Sequential T20 optimization research models game state and role deployment. | Test a distributional booster only if mean/variance calibration remains a measured weakness. Try chronological interval adjustment only with enough independent match blocks and report observed coverage under shift. Try a local foundation model only on the same player-match table as a bounded challenger. A sequential state model is worthwhile if verified states and held-out calibration support it. [NGBoost](https://proceedings.mlr.press/v119/duan20a.html) · [Online conformal inference](https://jmlr.org/papers/v25/22-1218.html) · [TabPFN research](https://www.nature.com/articles/s41586-024-08328-6) · [T20 tactical simulation preprint](https://arxiv.org/abs/2604.13861) |

These papers motivate tests. The winning model must earn its place on the supplied RR matches under the same prediction target and time boundaries. Treat simulation as an analysis tool and keep generated outcomes outside model training and evaluation. Public match records may verify or enrich the same RR rows. Keep the supplied match population and raw files intact.
