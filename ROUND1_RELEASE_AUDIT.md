## What held up

- All seven input file hashes match the saved input manifest. The input manifest hash and all seven output hashes listed by the hardened run match the files on disk. The local suite returned **85 passed** with a Windows core-detection warning. I reproduced forecast scores from the saved inputs and estimator. I did not run a second end-to-end rebuild in this review.
- The pack lists 883 fixtures. 867 have event rows. 806 meet the existing regulation cohort rules, accounting for 192,279 of 200,999 delivery rows. All 200,999 rows in the current ledger are marked as off-bat proxy state. The eligible split has 482 training matches, 191 in 2025 and 133 in the previously inspected 2026 period ending 1 November.
- The model really fits quantile gradient boosting. Its reported 2025 result reproduces when it receives the same inputs as the historical code. Pinball loss measures quantile forecast error in the same units as the impact rate. Lower is better. Q25 calibration compares the share of realized outcomes at or below the forecast with the intended 25%.

## What to build next

Fix provenance, event attribution and the forecasting information set first. Use one target and one forecasting interface, then rerun the simple cricket and shrinkage baselines, robust partial pooling and a regularized quantile booster. Train a booster only on features that can be reproduced at the ranking cutoff. Evaluate IPL transfer explicitly, with a predeclared phase and opposition context for supported scenarios. Keep player baseline, pressure lift, lower-tail prediction, rank uncertainty and auction eligibility as separate fields. If lift fails the temporal comparison, a player can still rank highly for reliable performance in difficult situations.

The technical foundations are T20-specific partial pooling and target-sensitive innings, context-adjusted run and wicket residuals, calibrated probabilistic forecasts, and realistic treatment of modelled leverage. The 2026 cricket preprints motivate testable variants and do not validate this pipeline. The useful evaluator-facing addition is a paired evidence card for each pick that quantifies IPL support, rank sensitivity, a real delivery sequence and a condition that would change the recommendation. [Davis, Perera and Swartz T20 simulator](https://www.sfu.ca/~tswartz/papers/t20sim.pdf) · [Bandyopadhyay's 2026 T20 evaluation preprint](https://arxiv.org/abs/2608.18020v2) · [Mishra's 2026 calibration and leverage preprint](https://arxiv.org/abs/2608.14696)
